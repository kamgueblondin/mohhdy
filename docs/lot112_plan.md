# Lot 112 plan - line-height passed to the engine, line-height math with percentages and numbers, rlh, all/revert on line-height, comparable arguments of mixed min()/max(), var() in keyframes, var() invalid at computed-value time; second commit: ex and ch of the actual font, ex/ch/lh/rlh in font-size, var() in every keyframe, unset for every kind, the body against html width auto

Base: 48709b8 (origin/main). PR 269 (the Lot 111 branch) is merged into
origin/main, so the branch starts from origin/main. Branch cursor/lot112.
One guest engine (userspace/webeng.c and its .inc files, unchanged in this
lot: the engine already reads line-height from a style attribute). Kernel,
rights and ABI unchanged. US-031 stays partial. phase3_complete stays
false. US-068/US-073, US-076, US-080 and US-081 stay partial. US-078 and
US-097 stay simule.

Scope taken from the "Not done" gaps of docs/lot111_plan.md, in the order
of the brief: line-height passed to the engine; line-height with a
percentage inside a math function; rlh; all and revert on line-height;
partial comparison of comparable arguments in mixed functions (so more
values fit the engine's bounds); var() in opacity keyframes and opacity
transitions from a var() value; var() invalid at computed-value time for
opacity (and line-height). Added: var() in color and background-color
keyframes. ex and ch against the element's actual font are not done (see
Not done) in the first commit.

Second commit (on top of d1e6a87, from the first commit's Not done, in
the order of the follow-up brief): ex and ch against the element's actual
font with the engine's own glyph metrics; ex, ch, lh, rlh (and the other
box units) in font-size; var() in registered properties' keyframes and
var() invalid at computed-value time unset for every property kind the
reader reads; the body's percentage width against an html width left
auto. No engine or ABI change was needed. No margin collapsing, no new layout or font engine, no JS VM.

A row is listed only when its code, tests and docs are in the branch.

## Not done (first gaps for lot 113)

1. Fonts: ex and ch with fonts the engine does not have (only its scaled 8x8 font; cap, ic and the units of other fonts are not read); the engine's per-level rounding of em chains (review point 13).
2. Line height: a unitless number is passed as px, not as a number the engine would inherit; the engine's bounds (10..40 px) cut larger or smaller line heights; fractions of a px are cut.
3. Math: a mixed value past the engine's bounds after dominance (more than 4 incomparable arguments, 24 nodes, 4 functions deep, 63 bytes) is still lost.
4. var(): invalid at computed-value time stays a drop for the properties outside the kinds (height, width, timelines, box lengths: they would need an initial value per property); an animated registered property read by another one's keyframe is read below the animations.
5. Box scrollers: an html height left auto leaves the body's percentage height auto (CSS 2 10.5); an html width auto with an html margin or padding leaves the body's percentage width to the engine.
6. Geometry, colours, fonts, gradients, @property, autofill, PSL, NE2000, shaping, US-080 and US-081: as in docs/lot111_plan.md.
