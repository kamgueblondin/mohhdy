# AOS-126 — SHA-256 caller-owned

Le lot AOS-126 introduit une primitive SHA-256 freestanding avec contexte, mise à jour fragmentée et finalisation caller-owned. Le contexte contient uniquement l’état, le compteur de bits et un bloc de 64 octets; aucune allocation dynamique n’est effectuée. La primitive est destinée aux futures vérifications d’intégrité TLS et de certificats, sans prétendre fournir encore une validation X.509.

Les tests vérifient les vecteurs officiels de la chaîne vide et de `abc`, avec mise à jour en fragments. La validation locale est de **282 tests verts**, avec build i386 et initrd réussis.
