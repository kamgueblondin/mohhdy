## What landed

- US-067: gRPC calls (HTTP/2 frames, HPACK subset, protobuf) carried as
  application records of the guest TLS 1.2 session between two guests
  (`OS_PEER_TLS_APP_SEND` / `OS_PEER_TLS_APP_RECV`, AES-128-GCM). The hub
  checks that no gRPC preface, path or payload crosses the wire in clear.
- US-099: contract language MCL (`collab_mcl_compile`, `collab_mcl_eval`):
  clauses `pay|refund|split N if COND...`, conditions on sign-offs, payee,
  arbiter and elapsed Lamport time; programs are ledger entries
  (`collab-contract-deploy`, `collab-signoff`), evaluated deterministically
  on every replica after each entry.
- US-104: compliance self-check with six computed checks, signatures
  re-verified against the bound keys, erasure verified, a GDPR article map
  (self-check, not a certification).
- US-112: offline signature database (built in, or a file in the same
  format), hex patterns and FNV hashes, severities, `prod-sec-db`.
- US-115: learned failure predictor (Q12 logistic regression trained in
  the guest on labelled windows, `prod-maint-train`, `prod-maint-predict`).
- US-083: `devsync-pull` asks a peer guest for the entries it has not seen
  (version vector in the request), over the sealed P2P channel; both ways,
  concurrent writes resolved by last-writer-wins, equal digests, no
  plaintext on the wire (`make qemu-p2p`, scenario 1b).
- US-077: `mobile-ui ARGS` typed on the OS-UI VBE desktop paints the phone
  frame (status bar, icon grid with labels, app bar, recents, shade, nav
  bar) through the web pane display list (`mui_display_list`); the unit
  test rasterizes the list and compares every pixel with the pixel model;
  `make qemu-osui-gui` checks the framebuffer. Touch input stays simule.
- US-103: Schnorr NIZK proof of knowledge in a 2048-bit group with a
  256-bit prime-order subgroup (`csig_zk_*`, `collab-zk-strong`),
  parameters generated by `scripts/gen_zk_group.py` from fixed labels and
  checked in the guest (q | p-1, g^q = 1, Fermat on p); known answer test
  against an independent Python run. Not constant time.
- Root-cause fixes found by CI: the shell prompt is written in one call (a
  kernel line from another task could split the `ESC[0m : ` needle), the
  collab job creates its log directory.
