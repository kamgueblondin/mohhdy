# AOS-209 à AOS-216 — DER/X.509 minimal caller-owned

Ce macro-lot apporte une lecture DER bornée et un parseur X.509 minimal pour les certificats reçus dans le handshake TLS. Il ne copie aucun certificat : toutes les vues publiées pointent vers le buffer de certificat possédé par l’appelant.

| Capacité | État |
|---|---|
| Lecture TLV DER courte et longue | Implémentée avec contrôles de bornes |
| Séquence X.509 principale et TBSCertificate | Parsée |
| Serial, issuer, subject, dates de validité | Exposés sans copie |
| SubjectPublicKeyInfo RSA | Modulus et exponent exposés sans copie |
| Raccordement au handshake TLS | Analyse X.509 explicite après Certificate |
| Validation de chaîne, dates, nom d’hôte et signature | Non implémentée |

Le lecteur rejette les longueurs indéfinies, les longueurs longues hors borne et les TLV tronqués. Le parseur X.509 exige les séquences structurantes attendues, une clé publique RSA encodée dans un BIT STRING à zéro octet inutilisé, et des entiers modulus/exponent non vides.

> L’extraction d’un certificat structuré ne vaut pas authentification. Aucune chaîne de confiance, contrainte d’usage, validation temporelle, vérification de signature de certificat ou correspondance de nom d’hôte n’est encore appliquée.
