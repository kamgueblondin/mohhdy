## Review points

1. The @scope lists cost memory: wf_site_t (one static in wf_html.c) grows from 279184 to 304336 bytes (8 scopes x 2 lists x 3 selectors x 4 compounds of 196 bytes).
2. IDN hosts are compared after a small hand-written case map, not UTS-46 (no NFC, no full mapping table, no bidi or contextual rules).
3. The paint cost is wall time between two tick reads around the fill and blit (10 ms ticks): it includes any task the scheduler runs in between, and a paint shorter than a tick reads 0. The shell task's own CPU ticks were not used: the getc wait yields back to the same task when nothing else runs, so they count the wait as work.
4. Autofill dates come from the CMOS clock in UTC; the session file format moves to version 2 (a fourth field). A build before this lot refuses a version 2 file (the tab is a control character in a value), it does not misread it.
5. The test server bug found while moving the steps: a route that ended with a bare `return` fell through to the next routes and wrote a second response on the same keep-alive connection; the guest's next connect then waited past the 5 s relay timeout ("[NET] relay timeout", "TCP connect failed" on the following page, every run). The routes of this lot return True. The guest side was found in chunk 2 (row G): the stray bytes were never the problem by themselves, the NE2000 ring was. With the fix, the deterministic repro (stray page, 12 s, next page) loaded the next page in 4 runs out of 4; 2 of them went through one ring resync (header 0 0 0 4), 2 needed none. Whether those 2 would have hit the old 1514 byte refusal was not measured.
6. Row H covers stray bytes read together with the answer; in the QEMU run both stray pages were caught that way (the count went 1 then 2). Stray bytes that arrive in a later read are still taken as the next answer on that connection (no non-blocking peek in the socket ops).

7. Row I costs memory: wf_site_t grows from 304336 to 331272 bytes (a node keeps a value index and a rank per name, a rule its custom value and the raw text of a declaration to read again).
8. While checking row I, `make qemu-lot88` run at the same time as `make qemu-lot87` failed once on its first page fetch ("send failed", the kept-alive retry included); run alone it passed (637.8 s) and CI on ca36f88 passed its Lot 88 jobs. Seen under two QEMU guests on one box only; not explained further.

## Not done (first gaps for lot 90)

1. Reader sheet: background images, gradients and positions are not passed on (one colour only); list-style-image is ignored; calc() cannot mix em with px (the parent size is not known when the sheet is read), rem is 16 px whatever the root size, and a declaration value is cut at 47 bytes, so a long clamp() is dropped.
2. Custom properties per element (row I) are bounded (12 names, 32 values of 31 bytes) and a property defined from another one is expanded where it is used, not where it is declared; @property, registered types and initial-value are not read.
3. @scope: no @import scope(); the start and end lists hold three selectors (a longer list keeps three, counted as an error); proximity counts generations, capped at 6.
4. Autofill dates: one date per key (its last store), not per value and not per fill (a value offered and accepted without typing does not refresh it); nothing expires on its own: forget-older has to be asked; UTC, no time zone.
5. US-081: the dim is a lower refresh only (no backlight); the paint time saved is estimated (skipped wakes x average cost), never in watts (no ACPI, battery simulated); on a paint-bound CI runner the loop is slower than every budget and nothing is saved.
6. Networking: the Ring 3 worker reads the card only during a relay op, so a burst that arrives between ops can fill the 26 page ring; QEMU then overwrites unread packets (its full test treats next page == boundary as empty). Row G recovers by a resync that drops what is pending (TCP resends); draining the ring between ops, or a larger ring, is not done. Stray bytes that arrive after the answer was read completely are not detected (review point 6).
7. Carried from Lot 88 and not touched yet: the title bar height does not follow the scale; no overscan margin is drawn on a TV (US-080, no DDC, mode set unchanged); the shaping queue is one eight-entry queue per node with fixed classes (US-068/US-073, no WAN); public suffixes are 126 hand-written entries, not the PSL.
