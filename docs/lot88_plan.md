## Review points

1. The panel trace is one serial line per key in a panel only (not in the chat, the editor or the web pane).
2. Scope proximity counts generations only and is capped at 6 hops (7 levels in 3 bits of the rank); the rule order now uses 7 bits (WF_SITE_RULES is 128, so it still fits).
3. The fw_cfg EDID file is a test harness hook like opt/mohhdy/ui-scale: it is read only when QEMU passes it and only replaces what the BAR2 block would have given.
4. The title bar keeps its height (30/34 px) at every scale; the buttons grow with q up to title - 6 (24 px for the app and pane bars at 2x, 28 for the chat). The title text is capped at the chrome scale as before.
5. The suffix list is not the Public Suffix List. A private hosting suffix that is not listed lets its subdomains share autofill values. See the gaps.

## Not done (first gaps for lot 89)

1. Reader sheet: background images, gradients and positions are not passed on (one colour only); font-size has no calc() or clamp(); list-style-image is ignored.
2. @scope: no @import scope(), no sibling hops in proximity, :scope cannot share a compound with another pseudo-class, the start/end selectors take one selector (a list keeps the first, counted as an error). Variables (--x) declared inside @scope are not read.
3. Chrome: the title bar height does not follow the scale (buttons capped at title - 6); keyboard window moves and snapping are not tested; the chrome test does not cover the editor and terminal windows of earlier lots (they have their own QEMU tests).
4. US-081: the dim is a lower refresh only (no backlight, no real panel power state); a loop already slower than the budget saves nothing (a CI runner paints in about 250 ms under TCG, so it wakes about 4 times a second and skips no frame); the CPU time saved is not measured in watts (no ACPI, battery simulated); the kernel getc still wakes the loop every 10 ticks, so the deepest budget below that rate is what matters.
5. TV: no overscan margin is drawn (only reported); the mode set is unchanged (no CEA mode is programmed, no DDC/I2C); the hint applies on a first boot only.
6. Public suffixes: 126 hand-written entries, not the PSL (thousands of entries, private ones change often); no IDN (punycode) handling.
7. US-068/US-073: the shaping queue holds eight datagrams for the whole node (3.3 KiB); the classes are fixed (messages, puts), not set per application; the eviction drops a datagram (a pushed-out put is repaired by anti-entropy, a pushed-out message is lost and counted in shaped_dropped); still no WAN and no cross traffic.
