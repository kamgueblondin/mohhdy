MOHHDY agent runtime

Origine HTTP Agent Support. Pas le noyau i386. LLM = echo stub local.

Sessions visiteur, base autorisee, droits, escalade et handoff (ASSIST-010 / 011 / 012 / 030 / 031 / 040 / 041). Les reponses agent sont un stub local, pas un LLM de production. Pas d'actes navigateur, pas d'appel reseau payant. Proteger l'admin avec ADMIN_TOKEN a l'execution, jamais dans l'image.

Routes :

  • GET /health - JSON de sante
  • GET /admin - console (liste, file, takeover)
  • GET /embed.js - widget public
  • GET /demo - page hote qui charge embed.js
  • POST /api/sessions - ouvrir une session visiteur
  • POST /api/sessions/{id}/messages - deposer un message
  • POST /api/sessions/{id}/escalate - demander un humain
