Instance Mohhdy (scaffold userspace)

Devoirs du SE (embed, sessions, admin). Pas le noyau i386 guest. LLM = echo stub local.

Sessions visiteur, base autorisee, droits, escalade, handoff, gestes simulateur, facture mock, vue navigateur d'instance et FS sandbox (ASSIST-010 a 022 / 030 / 031 / 040 / 041 / 060 / 061). Les reponses agent sont un stub local, pas un LLM de production. Les gestes sont un simulateur DOM, pas Chromium par defaut. Playwright est un profil optionnel (controle /browser, pas US-031). /browser n'est pas US-031 (phase 3 absente). Pas d'appel reseau payant. Proteger l'admin et le FS avec ADMIN_TOKEN a l'execution, jamais dans l'image.

Routes :

  • GET /health - JSON de sante
  • GET /admin - console (liste, file, takeover)
  • GET /embed.js - widget public
  • GET /demo - page hote qui charge embed.js
  • GET /demo-app - appli hote mock (menu, facture)
  • GET /browser - vue navigateur d'instance (simulateur, profil Playwright optionnel, pas US-031)
  • GET /browser/fs - explorateur FS sandbox
  • POST /api/browser/navigate - ouvrir une URL allowlistee (501 si Playwright absent)
  • POST /api/sessions - ouvrir une session visiteur
  • POST /api/sessions/{id}/messages - deposer un message
  • POST /api/sessions/{id}/escalate - demander un humain
  • POST /api/sessions/{id}/tools - geste ou outil MCP allowliste
